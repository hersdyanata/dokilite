# Doki Lite

Lightweight desktop widgets for Windows 11: system monitor, weather, launcher, battery, calendar, Wi-Fi & Bluetooth, clock, and Now Playing. Uses about 10 MB of RAM.

## Download

Get the latest **Doki-Lite-Setup-x.y.z.exe** from [Releases](../../releases/latest) and run it. No admin rights needed.

> If Windows shows "Windows protected your PC", click **More info → Run anyway**. The installer isn't code-signed yet.

## Updates

Doki Lite checks for new versions on its own. When one is ready, open Doki Lite and click **Update** (or use the tray menu). It closes, updates, and opens again by itself.

This repository only hosts the installers.
